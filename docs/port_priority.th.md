# USB Port priority

Y90 (รุ่นนี้หายาก ใครมีส่งมาหน่อย) กับ Y700 เจน 2 ใช้ระบบ priority บน usb เหมือนกัน (Y70 นี่ หัวควยมาก อันนี้เขียนด่าแยกได้เลย เพราะ type c driver ที่ใช้แม่งส้นตีนที่สุดตั้งแต่เคยทำอะไรพวกนี้มา)

- ถ้าต่อจอนอกเข้า C1, C2 จะใช้ได้แค่ชาร์จ เสียบ usb drive ไม่ก็ dac แต่จะต่อ usb drive (ที่เป็น data) ผ่าน hub ไม่ได้ (เมาส์กับคีย์บอร์ดยังได้ปกติ)
- ถ้าต่อ usb hub เข้า C1, C2 จะชาร์จได้อย่างเดียวเพราะมันไปออกกันที่ C1 หมดแล้ว
- ถ้าต่อ dac เข้า C1, C2 จะชาร์จได้อย่างเดียว

เพราะงั้น ไม่ว่าจะทำเชี่ยอะไร แพลนก่อนว่าจะเสียบอะไรบ้าง

ปล. ใน zui source code, มันบอกว่าอย่าต่อ usb data สองช่องจริงๆนะ
